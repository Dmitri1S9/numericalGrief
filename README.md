This is a project with solutions of a TU Wien course Numerical Computation.

## Setup

Activate the environment: `source .venv/bin/activate` (fresh install: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`).
Run: open the folder in VS Code and select the **numcomp** kernel, or run `jupyter notebook` from the activated environment.
